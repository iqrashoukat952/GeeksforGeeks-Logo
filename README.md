# GeeksforGeeks-Logo
A pixel-perfect recreation of the GeeksforGeeks logo using pure HTML and CSS.

## Project Overview
This project demonstrates how to recreate the GeeksforGeeks logo using only HTML and CSS, without any external libraries or images.

## Files
- `index.html` — Contains the structure and styling for the logo.

## How to Run
Open `index.html` in a browser to view the logo.

## Notes
The design is built using CSS borders, pseudo-elements, and positioning to mimic the original GeeksforGeeks brand mark.
